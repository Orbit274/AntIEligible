## Running Locally
To run the website locally, you need to start both the frontend and backend servers in separate terminals

## 1. Start the frontend (Port 5173)
Open a terminal and navigate to the `frontend` folder

```bash
cd frontend
npm run dev
```

The frontend will be available at `http://localhost:5173`

## 2. Start the backend (Port 3001)
Open a second terminal and navigate to the `backend` folder

```bash
cd backend
npm start
```

The backend will run at `http://localhost:3001`

## 3. Access the website
Once both servers are running, you can open the local url for the frontend in your browser
